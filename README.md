# GAGE Reimagined

You are acting as a senior website strategist, conversion designer, UX/UI designer, local SEO specialist and frontend developer.

Build a complete, production-ready replacement website for:

GAGE Center
Existing website: https://www.gagecenter.com/
Location: 1101 NW Jefferson St, Blue Springs, MO 64015
Phone: (816) 229-7775
Email: [info@gagecenter.com](mailto:info@gagecenter.com)

IMPORTANT PROJECT CONTEXT

This is a complete strategic rebuild, not a visual reskin and not a page-for-page copy of the existing website.

The existing website contains valuable brand history, program information and recognizable visual elements, but it has major problems:

* Confusing and oversized navigation
* Weak trial-class conversion journey
* Too many competing calls to action
* Excessively long pages
* Repetitive and generic messaging
* Inconsistent layouts and visual styles
* Outdated seasonal content and links
* Poor heading structure
* Misspelled and unfinished URLs
* Unclear program information
* Premature handoff to iClassPro
* Insufficient pricing, age, schedule and first-class information
* Weak mobile usability
* Missing or insufficient trust information
* Improper image alt text
* Poor accessibility structure
* Insufficient SEO structure
* Broken, unclear or mislabeled links

Do not copy these weaknesses into the new website.

PRIMARY BUSINESS OBJECTIVE

Convert local parents of preschool and school-age children into scheduled trial classes.

The website should make it easy for a parent to:

1. Understand what GAGE offers.
2. Find the right program for their child.
3. Understand what happens during a trial.
4. Trust the facility, staff and process.
5. Book a trial without entering a confusing registration system.
6. Receive confirmation and follow-up through One Konnector.
7. Enroll through iClassPro after GAGE recommends the appropriate class.

PRIMARY CALL TO ACTION

Book a Trial Class

SECONDARY CALL TO ACTION

Find the Right Class

Do not use “Register” as the primary public-facing call to action.

BRAND PRESERVATION

Preserve GAGE’s recognizable brand identity and history.

Use the uploaded official GAGE logo as supplied. Do not redraw, reinterpret or replace the logo.

Core visual direction:

* Black as the primary foundation color
* GAGE red as the primary action and accent color
* White and warm light gray for readability and openness
* Use purple only when it belongs to an approved program identity or existing brand element
* Strong athletic energy without making the site feel aggressive
* Friendly, safe and welcoming for parents and young children
* Modern, credible and established
* Clean, premium and highly organized
* Strong contrast and generous spacing
* Rounded corners may be used subtly, but do not make the website feel like a generic SaaS company
* Avoid excessive gradients, floating cards, glass effects and unnecessary animation
* Avoid trendy design treatments that weaken the established GAGE identity

The new visual identity should feel like:

“An established gymnastics institution made clear, modern, welcoming and trustworthy.”

Do not make it feel like:

* A generic children’s template
* A startup software company
* An elite-only gymnastics organization
* A trampoline park
* An AI-generated website
* A collection of unrelated landing pages

PHOTOGRAPHY DIRECTION

Prioritize authentic, approved GAGE photography featuring:

* Recreational children learning
* Preschool children participating
* Ninja and tumbling activities
* Caring coaches interacting appropriately with children
* Parents and children arriving
* The facility
* Small achievements, smiles and confidence
* A range of ages and skill levels

The homepage should not be dominated by elite gymnastics imagery. GAGE’s competitive legacy can be acknowledged, but the main sales journey should speak to ordinary local families and beginner children.

Do not invent or generate images that appear to depict real GAGE customers, coaches, testimonials, programs or facilities.

If approved photography is unavailable, use clear image placeholders labeled with the exact type of authentic photograph required.

BOOK-A-TRIAL FUNNEL

Create a dedicated, distraction-free trial page.

The form must be designed for integration with One Konnector/GoHighLevel.

Collect:

* Parent or guardian first name
* Parent or guardian last name
* Mobile number
* Email address
* Child’s first name
* Child’s age or date of birth
* Program interest
* Previous experience
* Preferred days
* Preferred time range
* Parent questions or accommodations
* Required SMS consent
* Required privacy consent

Do not collect unnecessary sensitive information.

Add appropriate TCPA-compliant consent language supplied by GAGE/One Konnector. Consent to marketing must not be hidden or preselected.

After submission:

* Do not immediately send the family into iClassPro.
* Display a clear confirmation.
* Explain that GAGE will review the information and recommend an available class.
* Provide a click-to-call option.
* Trigger the One Konnector workflow.
* Pass source, campaign, landing page and program-interest data into GHL.
* Include support for Meta Pixel and Google Analytics conversion events.

Create these trackable events:

* view_trial_page
* start_trial_form
* submit_trial_form
* click_phone
* view_program
* click_iclass_enrollment
* click_parent_portal

WORKING PROCESS

Do not attempt to generate the complete website in one unreviewed pass.

Start by producing:

1. The proposed sitemap
2. The navigation structure
3. The design system
4. A low-fidelity homepage wireframe
5. The Book-a-Trial funnel wireframe
6. A list of missing content and assets

Stop and request approval after those six items.

After approval, build only:

* Global navigation
* Homepage
* Book-a-Trial page
* Trial confirmation page
* Mobile versions

Stop again for review before creating the remaining pages.

The goal is not simply to create a more attractive website. The goal is to create a trustworthy, maintainable and measurable enrollment system that preserves GAGE’s brand while making it significantly easier for local parents to select a program and schedule a trial.
